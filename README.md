# Stopwatch

A desktop stopwatch application built with Python and PyQt5.

## Requirements

- Python 3
- PyQt5

## Installation

Clone the repository and open the project directory:

```bash
git clone https://github.com/wibisanabama/stopwatch-project.git
cd stopwatch-project
```

Install the required dependency:

```bash
python -m pip install PyQt5
```

## Usage

Run the application:

```bash
python main.py
```

Available controls:

- `Start`: Starts or resumes the stopwatch.
- `Stop`: Pauses the stopwatch.
- `Reset`: Stops the stopwatch and resets the elapsed time to zero.

## Project Structure

```text
stopwatch-project/
|-- main.py
`-- README.md
```

- `main.py`: Contains the user interface and stopwatch logic.
- `README.md`: Contains project documentation.
